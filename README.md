# small-document-finder
A Python script to recursively search a directory for PDF (or other specific) files smaller than a specified size and export their details to a text file.

## Features
- Recursively searches through all subdirectories
- Filters PDFs by size (default: <50KB)
- Exports results with absolute paths and filenames
- Handles common errors (permission issues, missing directories)

## Requirements
No additional installation required - uses Python's standard library.
